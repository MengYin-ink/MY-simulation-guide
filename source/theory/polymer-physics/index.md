# Polymer Physics

Polymer physics connects chain and network structure to material-scale
behavior. Useful descriptors include chain conformation, network connectivity,
crosslink density, composition, and spatial correlations.

Simulation observables must be interpreted within the model and sampling
limits. For example, a radial distribution function can describe spatial
correlations, but does not alone establish a macroscopic transport property.
See [structural analysis](../../polymerization/structural-analysis/index) for
the project workflow that relates trajectory observables to questions about
network morphology.
