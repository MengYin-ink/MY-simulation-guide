# Getting Started

Start here if you are new to computational materials science or this guide.

This section introduces shared tools and conventions. Begin with the command
line and project organization, then set up a software environment, use version
control, and connect to a research computing system.

## Suggested learning path

1. Learn basic Linux command-line operations.
2. Create a reproducible Python or software environment.
3. Use Git to track scripts and documentation.
4. Connect to an HPC system using [SSH](../computing/hpc/ssh).
5. Follow a validated [simulation workflow](../workflows/index).

The site is organized from fundamentals through methods and software to
workflows and research applications. Software-specific details are kept
separate from general method descriptions to reduce duplication.
