# Getting Started

Start here if you are new to computational materials science or to this guide.

The guide follows the research path from scientific foundations to validated
calculations:

1. Learn the relevant [theoretical background](../theory/index).
2. Choose and understand an appropriate [computational method](../methods/index).
3. Follow a [reusable workflow](../workflows/index) and consult its
   [software guide](../software/index).
4. For polymerization and crosslinking, see the
   [project knowledge base](../polymerization/index).

## Research computing basics

The computing section collects practical setup and access instructions:

- [Linux and command-line basics](../computing/linux/index)
- [Python and reproducible environments](../computing/python/index)
- [Git and version control](../computing/git/index)
- [SSH and HPC access](../computing/hpc/index)

Use the [documentation guide](documentation-guide) to understand how this

## Documentation scope

The public site is for shareable theory, generic procedures, and validated
examples. Do not publish credentials, restricted system details, confidential
code or parameters, unpublished project-specific structures, or results
without authorization. See the [public/private boundary](../resources/public-private-boundary)
before contributing project material.
