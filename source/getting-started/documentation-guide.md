# Documentation Guide

This site separates scientific knowledge by purpose:

| Question | Section |
|---|---|
| What physical or chemical principles apply? | [Theoretical Background](../theory/index) |
| How does a computational method work, and what are its limits? | [Computational Methods](../methods/index) |
| How does the current polymerization research connect its stages? | [Polymerization Project](../polymerization/index) |
| How do I use a particular package? | [Software Guides](../software/index) |
| What is the reusable sequence of steps and checks? | [Reusable Workflows](../workflows/index) |
| How do I access computing infrastructure? | [Computing](../computing/index) |
| Where are templates, references, and shared guidance? | [Resources & References](../resources/index) |

Maintain one authoritative explanation for each concept and link to it from
related pages. Keep general methods and procedures reusable; put their
project-specific application in the project section.

## Page maintenance

For technical procedures, state scope, prerequisites, inputs and units,
software versions, steps, outputs, validation, limitations, and references.
Record the environment and date when a procedure was tested. Review
version-sensitive commands and external links when updating a page.

Before publication, follow the [public/private boundary](../resources/public-private-boundary).
