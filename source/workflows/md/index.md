# Molecular-Dynamics Workflows

Reusable MD workflows should separate model and force-field preparation,
minimization, equilibration, production sampling, convergence assessment, and
trajectory analysis. Report ensemble, timestep, temperature or pressure
control, sampling duration, and independent-run strategy where applicable.

For reactive network formation, see
[MD Polymerization & Crosslinking](../../polymerization/md-polymerization/index).
For package syntax, see the [LAMMPS guide](../../software/lammps/index).
