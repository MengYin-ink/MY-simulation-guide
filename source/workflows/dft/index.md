# DFT Workflows

Reusable stages for a DFT calculation include model preparation, convergence
testing, geometry optimization, property or reaction-path calculation,
validation, and analysis. Select and justify parameters for the scientific
question and system rather than copying settings without testing.

For reaction paths, see the dedicated
[CI-NEB workflow](../ci-neb/index). Software-specific input belongs in the
[VASP guide](../../software/vasp/index).
