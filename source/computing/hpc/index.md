# High-Performance Computing

General guidance for accessing HPC systems, submitting jobs, and using
allocated compute resources responsibly.

Start with [SSH access](ssh). Use the [AOBA guide](aoba/index) only for
information approved for public release; current account, host, and scheduler
instructions should be checked against official HPC documentation.

```{toctree}
:maxdepth: 1

ssh
aoba/index
```

Always follow the system's official policies. Login nodes are generally for
lightweight preparation and job submission, not production calculations.
