# Git and Version Control

Git records changes to code and documentation, supports collaboration, and
helps preserve the provenance of computational workflows.

For research projects:

- commit source files and environment specifications, not credentials or
  private data;
- use descriptive commits and review changes before publishing;
- tag or otherwise record versions used for reported calculations;
- keep large or sensitive datasets in an approved storage system rather than
  assuming the Git repository is an appropriate data archive.

Before making a repository public, review its current files and history for
secrets, private notes, unpublished results, and restricted material.
