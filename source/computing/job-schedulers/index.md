# Job Schedulers

HPC job schedulers allocate compute resources and run jobs according to
system policy. Common scheduler families include Slurm and PBS, but command
syntax, queues, limits, and policies are site-specific.

A job submission guide should identify the target system and approved
software environment, explain resource requests, provide a minimal
non-sensitive example, and show how to inspect job status and output. Verify
all commands against the cluster's current official documentation.

Do not treat scheduler examples as universal defaults or run production
calculations directly on login nodes. See the [HPC overview](../hpc/index).
