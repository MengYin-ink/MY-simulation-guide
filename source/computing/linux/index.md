# Linux

Linux command-line tools are commonly used to prepare and inspect simulation
inputs, manage files, and submit jobs on HPC systems.

Start with navigation and file operations such as `pwd`, `ls`, `cd`, `mkdir`,
and `cp`. Learn to inspect text files and command output, and use shell
scripts only after understanding their inputs and effects.

For remote access, see [SSH and VS Code](../hpc/ssh). Avoid running
resource-intensive calculations on login nodes; follow the
[HPC guidance](../hpc/index) and the system's policies.
